## 🌐 Comment le mettre en ligne gratuitement en 2 minutes

### Option 1 : Netlify Drop (La méthode la plus rapide sans code - 60 secondes)
1. Rendez-vous sur [app.netlify.com/drop](https://app.netlify.com/drop).
2. Glissez-déposez le dossier de ce projet (`Antigravity`).
3. Votre site est immédiatement en ligne avec un lien HTTPS personnalisé partageable sur votre CV et LinkedIn !

### Option 2 : GitHub Pages (Idéal pour les profils Data & Tech)
1. Créez un dépôt public sur votre compte GitHub (ex: `portfolio-souleymane-bah`).
2. Publiez le fichier `index.html`.
3. Allez dans les réglages du dépôt (**Settings** $\rightarrow$ **Pages**) et activez la branche `main`.
4. Votre site sera accessible à l'adresse : `https://<votre-pseudo>.github.io/portfolio-souleymane-bah`.

### Option 3 : Vercel
1. Connectez votre dépôt GitHub sur [vercel.com](https://vercel.com).
2. Cliquez sur **Deploy** : le site est en ligne instantanément.
